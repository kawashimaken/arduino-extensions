# W5100 Ethernet プロジェクト

W5100用のサンプルをプロジェクトごとのフォルダにまとめています。
各フォルダは独立したPlatformIOプロジェクトです。

| フォルダ | 内容 |
| --- | --- |
| [01_basic_web_server](01_basic_web_server/) | 最初のシンプルな通信確認サンプル。DHCPでIPを取得し、ブラウザにIPアドレスと起動後の秒数を表示します。 |

VS Codeでは、実行したいプロジェクトのフォルダ（`platformio.ini` のあるフォルダ）を開いてください。
接続・書き込みの手順は各プロジェクトのREADMEに記載しています。

今後のプロジェクトも `02_名前`、`03_名前` のように、このフォルダの下へ追加します。
